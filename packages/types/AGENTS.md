# AGENT NOTES — `@sora-substrate/types`

## Responsibilities
- Adapt the raw definitions from `@sora-substrate/type-definitions` into Polkadot.js-consumable bundles (`types`, `typesAlias`, `typesBundle`, `rpc`).
- Host generated TypeScript interface augmentations under `src/interfaces` so downstream code has static typing for SORA pallets.
- Provide metadata export scripts that dump chain metadata JSON per environment.

## Directory Tour
- `src/index.ts` wires definitions into Polkadot.js override bundles and re-exports the generated interfaces.
- `src/interfaces/augment-*.ts` are auto-generated by `polkadot-types-from-defs`. Do not hand-edit; rerun generation scripts instead.
- `src/metadata/` stores JSON snapshots:
  - `types.json` — `yarn export-types:<env>` writes the combined metadata.
  - `<env>/types.json` — environment-specific exports (test/stage/prod).
- `scripts/exportTypesJson.ts` and `scripts/exportApi.ts` connect to live nodes and update metadata/docs; ensure the target endpoints are reachable.

## Maintenance Flow
- After changing `@sora-substrate/type-definitions`, run:
  1. `yarn generate:defs:<env>` to regenerate interfaces.
  2. `yarn generate:meta:<env>` if you need updated metadata bundles.
  3. `yarn export-types:<env>` to persist JSON snapshots.
- Keep augment files committed; consumers rely on them for compile-time typing. If generation produces diffs, review for breaking changes and update dependants accordingly.
